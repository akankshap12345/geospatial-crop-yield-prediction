# Geospatial Crop Yield Prediction

##  Project Overview
This project predicts crop yield using machine learning techniques based on geospatial, weather, and soil data.

##  Model Used
- Linear Regression

## Dataset
- Historical crop yield data
- Weather parameters
- Soil properties

##  Tools & Technologies

- Pandas
- NumPy
- Scikit-learn
- Matplotlib

##  Model Evaluation

- R² Score
